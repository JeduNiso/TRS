# HTML RULES

Use semantic elements.

Maximum nesting depth

Five.

Comment every major section.

Use descriptive class names.

IDs only for navigation.

Never for styling.

---

# CSS RULES

Follow the Design System.

Never hardcode colors.

Never hardcode spacing.

Always use CSS variables.

Prefer Flexbox.

Use CSS Grid when appropriate.

Avoid unnecessary selectors.

Use BEM-inspired naming.

---

# JAVASCRIPT RULES

JavaScript enhances the interface.

It does not build the interface.

Keep modules independent.

One responsibility per file.

Prefer CSS over JavaScript whenever possible.

Use IntersectionObserver.

Avoid unnecessary dependencies.
